# pack
팩의 움직임을 알고 싶을때 쓰는 HTML

## 실행

별도 설치 없이 Python 3으로 정적 서버를 실행합니다.

```sh
python3 -m http.server 8000 --directory .
```

브라우저에서 서버의 `index.html`을 열어 사용합니다.

## 작업 화면

상단의 ‘파레트 → 시작맵 → 팩 번호 → 도착맵 → 경로’ 메뉴에서 현재 단계와 진행 상태를 확인합니다.
아직 필요한 작업을 마치지 않은 단계는 비활성화되며, 사용 가능한 단계를 누르면 해당 편집 도구로 이동합니다.
상단 도구 모음은 현재 단계에 필요한 주요 버튼만 보여줍니다. 다른 편집 단계는 위쪽 단계 메뉴에서 바로 열 수 있습니다. 시작맵·도착맵 보기 버튼은 편집 모드에 들어가지 않고 한 번에 배치를 전환하며, 보기 전환·3D·팩 변경 도구는 함께 모아 표시합니다.
PC에서는 팩 선택·번호판·경로 입력을 오른쪽 패널에서 사용합니다. 모바일에서는 팩 선택을 위쪽에 압축 표시하고 번호판과 경로 입력은 파레트 옆에 유지합니다.
현재 선택한 팩과 번호를 편집하는 칸은 강조 표시됩니다. 작업 공간 아래에서 현재 단계의 안내와 팩 색상 범례를 확인할 수 있습니다.

최대 40 × 40 격자에서 클릭한 칸에 검정 테두리와 빨간 번호가 표시됩니다.
마우스를 누른 채 드래그하면 지나간 칸이 연속으로 선택됩니다. 빠르게 움직여도 중간 칸을 채우고, 같은 칸을 다시 지나가도 선택은 유지합니다. 한 번 클릭하면 기존처럼 선택·해제할 수 있습니다.
처음에는 12 × 8 작업 격자를 표시하며, 가장자리 쪽으로 그리면 주변 격자가 자동으로 확장됩니다.
처음부터 0번 칸 하나가 선택되어 있습니다. 다시 클릭하면 삭제하거나 원하는 곳에서 새로 시작할 수 있습니다.
그리기를 마치면 선택한 파레트 영역만 화면 가운데에 자동으로 맞춰 표시합니다.
화면 크기와 팩 선택 도구의 표시 여부에 맞춰 칸 크기가 조정되어 작업 공간을 가로·세로로 스크롤할 필요가 없습니다.
선택 영역의 왼쪽 위를 원점으로, 빈칸을 포함해 가로부터 번호를 매깁니다.
다음 줄은 선택 영역 너비만큼 번호가 이어집니다. 선택 영역이 넓어지면 번호도 다시 계산됩니다.
선택 영역의 가장 위쪽 행과 가장 왼쪽 열이 만나는 칸이 0번이며, 이 칸이 선택되지 않았으면 0번은 표시되지 않습니다.
같은 칸을 다시 누르면 선택이 해제되고 나머지 번호도 다시 계산됩니다.
맞닿은 칸의 검정 테두리는 같은 위치에 겹쳐 일정한 두께로 표시됩니다.
‘파레트 그리기 종료’를 누르면 격자가 사라지고 선택한 칸만 남습니다.
‘파레트 다시 그리기’를 누르면 기존 선택을 유지하며 이어 그릴 수 있습니다.

## 리스트로 시작맵·도착맵 만들기

상단 ‘리스트로 맵 만들기’에서 `p=[...]`(시작맵)와 `e=[...]`(도착맵)를 함께 붙여 넣습니다.
한 줄이 한 행이고 쉼표로 칸을 구분합니다. 빈 줄은 다음 층을 뜻하며 최대 3층까지 지원합니다.
예를 들어 한 층에 6개씩 3줄, 빈 줄 뒤 다시 3줄을 입력하면 6×3 크기의 2층 맵입니다.
0은 빈칸, H는 홀, X는 사각 고정팩이며 일반 숫자·도형 번호는 사각 중형팩으로 생성됩니다.
시작·도착맵의 층별 크기와 번호별 팩 수량이 맞아야 합니다. 입력 오류가 있으면 현재 작업을 보존하고 오류를 안내합니다.
‘맵 만들기’를 누르면 현재 작업을 입력한 목록으로 대체하고 자동 저장합니다. 경로가 있으면 함께 붙여 넣고 ‘만들고 경로 확인’을 눌러 맵 생성과 경로 창 열기를 한 번에 할 수 있습니다. 함께 입력한 경로가 잘못되면 현재 작업을 대체하기 전에 오류를 안내합니다.

‘팩 바꾸기’를 누른 뒤 원하는 종류·크기를 선택하고 기존 팩을 클릭하면 번호와 배치 위치를 유지한 채 종류만 변경됩니다.
시작맵과 도착맵에서 같은 팩이 함께 바뀌므로 도착 위치나 번호를 다시 지정할 필요가 없습니다. 같은 종류를 다시 눌러도 팩이 삭제되지 않습니다.
시작맵의 일반 배치 모드에서도 다른 종류로 교체할 때 기존 번호를 유지합니다. 같은 종류를 다시 클릭해 지우는 동작은 일반 배치 모드에서만 적용됩니다.

## 시작맵

파레트 그리기를 종료한 후 ‘시작맵 만들기’를 누릅니다.
사각팩·원형팩의 소·중·대를 선택하고 파레트 칸을 클릭하면 팩이 배치됩니다.
같은 팩을 다시 클릭하면 제거되고, 다른 종류를 고른 후 클릭하면 교체됩니다.
한 칸에는 하나의 팩을 배치합니다. 파레트 칸을 삭제하면 그 칸의 팩도 삭제됩니다.
배치 종료·재개나 파레트 그리기 전환 시 기존 팩은 유지됩니다. 작업은 브라우저에 자동 저장되며 다음 접속 시 ‘전 내용 불러오기’로 복원할 수 있습니다.

사각팩의 밑면은 모두 2 × 2cm, 원형팩의 밑면은 모두 지름 2cm입니다.
두 모양 모두 소·중·대 높이는 각각 4·5·6cm입니다.
위에서 본 배치도에서는 밑면 모양을 표시하며, 크기 선택의 옆모습 미리보기는 가로·세로 동일한 축척(1cm당 20 SVG 단위)을 사용합니다.

사각팩은 빨간색, 원형팩은 파란색입니다.

## 팩 번호와 도착맵

시작맵 배치를 종료하면 ‘팩 번호 매기기’를 사용할 수 있습니다.
팩을 클릭하면 파레트 오른쪽의 별도 영역에 번호판이 열립니다. 화면 숫자 버튼이나 키보드로 0–999999의 정수 또는 도형 번호 ○(원)·△(세모)·□(네모)·◇(45도 기운 네모)를 입력하고 ‘저장 · 다음’ 또는 Enter로 저장합니다.
저장 후 같은 줄의 오른쪽 다음 팩으로 이동하고, 없으면 아래쪽 다음 줄의 가장 왼쪽 팩으로 이동합니다. 빈칸과 빈 줄은 건너뛰고, 현재 층의 마지막 팩 다음에는 다음 층의 팩으로 자동 전환합니다. 모든 층의 마지막 팩에서 번호판이 닫힙니다. 시작맵과 도착맵 모두 같은 순서를 사용합니다.
번호판이 열린 동안 현재 팩은 강조 표시되며, 다른 팩을 직접 클릭해 편집 위치를 바꿀 수도 있습니다.
같은 숫자나 도형 번호를 여러 팩에 사용할 수 있습니다. 모든 팩에 번호를 지정해야 번호 매기기를 완료할 수 있습니다. ‘닫기’나 Escape는 입력 중인 변경을 저장하지 않습니다. 입력 오류가 있으면 다음 팩으로 이동하지 않습니다.

번호 매기기를 완료하면 ‘도착맵 만들기’를 사용할 수 있습니다.
시작맵과 같은 파레트에서 별도의 배치도를 만들며, 시작맵의 종류·크기별 수량만 사용할 수 있습니다.
예를 들어 시작맵에서 사각팩 소를 2개 사용했다면 도착맵에서도 최대 2개만 배치됩니다.
같은 종류·크기의 팩은 시작맵 배치 순서대로 남은 팩을 사용하고 그 팩의 번호를 유지합니다.
배치한 팩을 지우면 해당 팩이 남은 수량으로 돌아옵니다. 다른 종류로 교체할 때도 수량을 초과할 수 없습니다.
시작맵의 모든 팩을 배치해야 도착맵을 완료할 수 있습니다. ‘시작맵 보기’로 원래 배치를 확인할 수 있습니다.

도착맵 배치를 완료하면 ‘도착맵 팩 번호 매기기’를 누르고 팩을 클릭해 번호판을 열 수 있습니다.
숫자 버튼과 키보드로 시작맵에 있는 같은 종류·크기의 팩 번호를 지정합니다.
이미 다른 위치에서 사용 중인 번호를 입력하면 두 위치의 팩 번호가 교환됩니다.
시작맵 번호는 변경되지 않으며, 같은 번호의 팩이 여러 개여도 각각 별도의 팩으로 관리하여 종류·크기별 수량을 유지합니다. 현재 번호를 다시 저장하면 해당 팩을 그대로 유지합니다.
‘도착맵 팩 번호 매기기 완료’를 누르면 번호 편집을 종료합니다.

## 3D 보기

그리기나 배치를 마친 상태에서 ‘3D로 보기’를 누르면 현재 시작맵 또는 도착맵을 입체로 볼 수 있습니다.
선택한 파레트만 표시하며, 한 칸의 밑면은 4 × 4cm입니다. 2D와 3D 모두 팩의 폭·지름 2cm가 칸 변 길이의 정확히 절반이 되도록 표시합니다.
사각팩은 폭·깊이 2cm인 빨간 직육면체, 원형팩은 지름 2cm인 파란 원기둥으로 표시합니다.
높이는 두 종류 모두 소·중·대 각각 4·5·6cm이며 팩 번호도 표시됩니다.
마우스·한 손가락 드래그 또는 방향키로 회전하고, 휠·두 손가락 제스처·확대/축소 버튼으로 크기를 조절합니다.
‘시점 초기화’로 전체 파레트 중심의 바로 위에서 수직으로 내려다볼 수 있습니다.
팩 번호는 2D에서 흰색으로, 3D에서는 흰색 글자를 팩 윗면에 직접 표시합니다. 파레트 칸 번호는 팩이 이동한 뒤에도 원래 위치에 남습니다.
‘2D로 보기’ 또는 편집 버튼으로 기존 배치와 번호를 유지하며 돌아옵니다.
3D 보기에는 WebGL을 지원하는 브라우저가 필요하며, 지원하지 않으면 오류를 안내하고 2D 편집은 유지합니다.
Three.js 0.180.0과 OrbitControls는 MIT 라이선스에 따라 vendor/three에 포함되어 외부 CDN 연결이나 설치가 필요하지 않습니다.

## 경로 추가와 이동 재생

시작맵 배치를 마치고 ‘경로 추가하기’를 누른 뒤 `[[9,8,18,16,11],[21,16,18,8,9]]` 같은 배열을 입력합니다.
숫자는 팩 번호가 아닌 **파레트 칸 번호**입니다. 첫 경로는 9번 칸의 팩을 8·18·16번을 거쳐 11번 칸으로 이동합니다.
경로들은 배열 순서대로 실행되며, 뒤 경로는 앞 경로의 이동 결과에서 출발합니다.
‘입력 완료 · 재생’을 누르면 경로 전체를 검증한 뒤 자동으로 재생합니다.
선택되지 않은 파레트 칸, 팩이 없는 출발 칸, 다른 팩이 있는 최종 도착 칸은 오류로 안내합니다. 경로 중간의 팩 처리 방식은 설정에서 선택합니다.
충돌 감지 모드에서는 지점 사이 이동 구간을 검사합니다. 팩 위로 통과 모드에서는 필요한 높이까지 올라가 수평 이동한 뒤 경유·도착 위치로 내려옵니다. 좌우 우회 경로를 자동 생성하지는 않습니다.

2D와 3D에서 실제 팩 이동을 볼 수 있고 일시정지·이어서 재생·처음으로 돌아가기를 지원합니다. ‘〈 이전’·‘다음 〉’으로 각 경유지 사이의 이동을 한 단계씩 확인할 수 있습니다. 처음 ‘다음’을 누르면 입력을 검증한 뒤 첫 이동 과정을 보여주고, ‘이전’은 현재 위치에서 이전 경유지까지 역방향으로 움직인 뒤 해당 배치를 복원합니다. ‘다음’도 한 이동을 애니메이션으로 재생한 뒤 멈춥니다. 팩 위로 통과하는 상승·하강과 층간 높이 변화도 양방향으로 표시합니다. 자동 재생 중 버튼을 누르면 일시정지 후 이동하며, 확인한 단계에서 ‘이어서 재생’할 수 있습니다.
재생 위치 슬라이더를 움직이면 원하는 이동 단계의 배치를 바로 확인할 수 있습니다. 경로 창에서 텍스트·입력창을 편집 중이 아닐 때 ←/→ 키로 이전·다음 이동을 확인하고 Space로 재생·정지를 전환할 수 있습니다. 버튼에 포커스가 있을 때 Space는 해당 버튼을 실행하며, 3D 캔버스의 방향키 회전은 그대로 유지합니다.
재생 중 2D/3D를 전환하면 일시정지되며 ‘이어서 재생’으로 계속할 수 있습니다.
경로 미리보기는 시작맵의 별도 복사본을 사용하여 원본 시작맵·도착맵과 팩 번호를 변경하지 않습니다.
도착맵이 있으면 재생 결과가 도착맵과 일치하는지도 표시합니다. 편집 모드로 들어가거나 경로 패널을 닫으면 미리보기가 종료됩니다.

시작맵이나 파레트를 수정하면 배치·번호 완료 상태를 다시 확인해야 합니다.
시작맵에서 삭제되거나 교체된 팩은 도착맵에서도 제거되며, 남아 있는 팩의 번호와 유효한 도착 위치는 유지됩니다.

## 경로 충돌 설정

상단 ‘설정’에서 다음 중 하나를 선택합니다. 기본값은 충돌 감지이며, 선택은 현재 브라우저에 따로 저장됩니다.

- **충돌 감지**: 경유 위치뿐 아니라 이동 구간이 다른 팩·X 고정팩과 겹치면 ‘부딪힘이 감지되었습니다’와 위치 번호를 안내합니다. 원본 배치는 변경하지 않습니다.
- **팩 위로 통과**: 경로의 다른 팩을 그대로 둔 채 그 윗면보다 높게 올라가 지나갑니다. 점유된 경유지에서도 아래 팩을 덮어쓰지 않고 이동 중인 팩을 별도로 표시합니다. 최종 도착 위치가 점유되어 있으면 두 모드 모두 충돌로 처리합니다.

설정을 바꾸면 기존 검증 결과와 재생 위치를 초기화하고, 다음 재생 때 새 설정으로 경로 전체를 다시 검사합니다. 3D에서는 상승·통과·하강을 표시하고, 2D에서는 통과 중 팩을 강조합니다. 이전·다음·슬라이더에서도 점유된 경유지 위의 팩을 확인할 수 있습니다.

## X 고정팩 · H 홀

파레트를 그리거나 팩을 배치하는 화면에서 ‘X 고정팩’ 또는 ‘H 홀’을 고른 뒤 칸을 클릭합니다. 같은 도구로 다시 클릭하면 일반 칸으로 돌아옵니다. ‘일반 칸’이나 팩 종류를 선택하면 보통 편집으로 돌아옵니다.
‘사각 X’는 빨간 대형 사각팩(2×2×6cm), ‘원형 X’는 파란 대형 원형팩(지름 2cm, 높이 6cm)으로 표시하며 윗면에 큰 검정 X가 있습니다. 움직일 수 없고 최종 도착 위치로 사용할 수 없습니다. 충돌 감지 모드는 X를 가로지르는 이동도 차단하며, 팩 위로 통과 모드에서는 고정팩 위로 지나갈 수 있습니다.
H는 팩이나 구멍 모형 없이 큰 파란 H 글자로 표시합니다. 경로 중간에 통과할 수 있지만 팩을 배치하거나 경로의 마지막 위치로 지정할 수 없습니다.
X·H는 파레트 칸 번호를 유지하며 시작맵·도착맵에 공통 적용됩니다. 기존 팩이 있는 칸을 X·H로 바꾸면 그 팩의 시작·도착 배치도 제거됩니다.
층별 자동 저장과 3D 보기를 지원합니다.

## 다층 파레트

작업 공간 위의 ‘＋ 2층 만들기’·‘＋ 3층 만들기’를 누르면 아래층의 칸 모양을 복사해 빈 위층을 만듭니다. 팩·고정팩·H 표시는 복사하지 않습니다. 이미 만든 층을 누르면 기존 작업을 보존한 채 전환합니다.
파레트 모양은 층별로 편집하지만 시작맵·도착맵·팩 번호·경로는 모든 층이 하나의 작업으로 공유합니다. 시작맵 편집 중 층 버튼을 눌러 다른 층에도 팩을 놓고, 모든 층의 배치를 마친 뒤 완료 버튼을 한 번만 누릅니다. 번호 매기기·도착맵도 전체 층을 기준으로 완료하며 팩 수량을 공유합니다. 층 전환으로 작업 단계가 바뀌거나 경로 입력이 초기화되지 않습니다.
파레트 번호는 아래층의 실제 마지막 번호 +1부터 이어집니다. 예를 들어 1층이 0–15이면 2층은 16부터 시작합니다. 빈칸을 포함한 기존 계산을 유지하며, 아래층 모양이 바뀌면 위층 번호도 다시 계산됩니다.
층 버튼에 번호 범위를 표시합니다. 경로는 모든 층의 번호를 하나의 배열로 입력합니다. 예를 들어 1층이 0–15이고 2층이 16부터라면 [[0,16,17]]로 1층에서 2층으로 이동할 수 있습니다. 3D에서는 높이가 연속으로 변하며 이동하고, 2D에서는 출발·도착 층을 자동으로 따라갑니다. 아래층을 수정해 번호가 달라졌다면 기존 경로도 확인해 주세요.
3D에서는 시작맵의 아래층 최대 팩 높이(고정팩 포함)를 기준으로 각 층 높이를 정하고, 재생 중과 도착맵에서도 그 높이를 유지합니다. 아래층에 팩이 전혀 없으면 기본 높이 6cm를 사용합니다. 아래 칸이 비어 있어도 위층 팩을 아래로 내리지 않으며 경유지·최종 도착지 모두 지정된 층에 그대로 표시합니다. 따라서 지지되지 않은 공중 배치 문제를 직접 확인할 수 있습니다. 위층 바닥은 두께 없는 투명한 안내면입니다.
위에서 내려다볼 때 위층이 아래층을 가릴 수 있으므로 드래그로 회전해서 전체 층을 확인하세요.
기존 단층 자동 저장 데이터는 1층으로 복원됩니다. 이전 층별 저장 데이터도 모든 층의 팩과 도착 배치를 보존한 통합 작업으로 변환합니다. 유효한 층별 경로 배열은 하나로 합칩니다.

## 자동 저장

파레트, 시작맵·도착맵, 숫자·도형 팩 번호, 종류별 선택 상태와 입력한 경로를 현재 브라우저의 localStorage에 자동 저장합니다.
입력 중인 팩 번호와 편집 단계도 복원합니다. 중복 번호 팩은 별도의 객체 식별을 유지합니다.
변경 후 약 0.2초 뒤 저장하며 페이지를 나가거나 숨길 때도 저장합니다. 제목 옆에 저장 중·저장됨·실패 상태가 표시됩니다.
사이트에 접속하면 항상 초기 화면(1층 기본 0번 칸)으로 시작합니다. 상단 ‘전 내용 불러오기’를 누르면 이번 접속 전에 저장된 모든 층의 작업을 복원합니다. 초기 화면을 보기만 하거나 그대로 나가면 기존 저장 내용을 덮어쓰지 않습니다. 새 작업을 편집하면 자동 저장이 시작되며, 같은 접속 중에는 새 작업을 편집한 뒤에도 ‘전 내용 불러오기’로 접속 전 작업을 불러올 수 있습니다. 브라우저 사이트 데이터를 삭제하면 저장된 작업도 삭제됩니다.
3D 카메라 위치와 경로 재생 중간 위치는 복원하지 않으며, 입력한 경로를 시작맵에서 다시 재생할 수 있습니다.
손상된 저장 데이터는 별도의 백업 키에 보존한 뒤 새 작업으로 시작합니다. 저장 공간 부족·차단 시에는 실패 상태를 표시하고 현재 화면의 편집 기능을 유지합니다.
