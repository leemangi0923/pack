# pack
팩의 움직임을 알고 싶을때 쓰는 HTML

## 실행

별도 설치 없이 Python 3으로 정적 서버를 실행합니다.

```sh
python3 -m http.server 8000 --directory .
```

브라우저에서 서버의 `index.html`을 열어 사용합니다.

## 작업 화면

상단의 ‘파레트 → 시작맵 → 팩 번호 → 도착맵 → 경로’ 메뉴에서 현재 단계와 진행 상태를 확인합니다.
아직 필요한 작업을 마치지 않은 단계는 비활성화되며, 사용 가능한 단계를 누르면 해당 편집 도구로 이동합니다.
상단 도구 모음은 현재 작업의 완료 버튼을 강조하고, 보기 전환·3D·경로 도구를 오른쪽에 모아 표시합니다.
PC에서는 팩 선택·번호판·경로 입력을 오른쪽 패널에서 사용합니다. 모바일에서는 팩 선택을 위쪽에 압축 표시하고 번호판과 경로 입력은 파레트 옆에 유지합니다.
현재 선택한 팩과 번호를 편집하는 칸은 강조 표시됩니다. 작업 공간 아래에서 현재 단계의 안내와 팩 색상 범례를 확인할 수 있습니다.

최대 40 × 40 격자에서 클릭한 칸에 검정 테두리와 빨간 번호가 표시됩니다.
마우스를 누른 채 드래그하면 지나간 칸이 연속으로 선택됩니다. 빠르게 움직여도 중간 칸을 채우고, 같은 칸을 다시 지나가도 선택은 유지합니다. 한 번 클릭하면 기존처럼 선택·해제할 수 있습니다.
처음에는 12 × 8 작업 격자를 표시하며, 가장자리 쪽으로 그리면 주변 격자가 자동으로 확장됩니다.
처음부터 0번 칸 하나가 선택되어 있습니다. 다시 클릭하면 삭제하거나 원하는 곳에서 새로 시작할 수 있습니다.
그리기를 마치면 선택한 파레트 영역만 화면 가운데에 자동으로 맞춰 표시합니다.
화면 크기와 팩 선택 도구의 표시 여부에 맞춰 칸 크기가 조정되어 작업 공간을 가로·세로로 스크롤할 필요가 없습니다.
선택 영역의 왼쪽 위를 원점으로, 빈칸을 포함해 가로부터 번호를 매깁니다.
다음 줄은 선택 영역 너비만큼 번호가 이어집니다. 선택 영역이 넓어지면 번호도 다시 계산됩니다.
선택 영역의 가장 위쪽 행과 가장 왼쪽 열이 만나는 칸이 0번이며, 이 칸이 선택되지 않았으면 0번은 표시되지 않습니다.
같은 칸을 다시 누르면 선택이 해제되고 나머지 번호도 다시 계산됩니다.
맞닿은 칸의 검정 테두리는 같은 위치에 겹쳐 일정한 두께로 표시됩니다.
‘파레트 그리기 종료’를 누르면 격자가 사라지고 선택한 칸만 남습니다.
‘파레트 다시 그리기’를 누르면 기존 선택을 유지하며 이어 그릴 수 있습니다.

## 시작맵

파레트 그리기를 종료한 후 ‘시작맵 만들기’를 누릅니다.
사각팩·원형팩의 소·중·대를 선택하고 파레트 칸을 클릭하면 팩이 배치됩니다.
같은 팩을 다시 클릭하면 제거되고, 다른 종류를 고른 후 클릭하면 교체됩니다.
한 칸에는 하나의 팩을 배치합니다. 파레트 칸을 삭제하면 그 칸의 팩도 삭제됩니다.
배치 종료·재개나 파레트 그리기 전환 시 기존 팩은 유지됩니다. 작업은 브라우저에 자동 저장되어 새로고침 후에도 복원됩니다.

사각팩의 밑면은 모두 2 × 2cm, 원형팩의 밑면은 모두 지름 2cm입니다.
두 모양 모두 소·중·대 높이는 각각 4·5·6cm입니다.
위에서 본 배치도에서는 밑면 모양을 표시하며, 크기 선택의 옆모습 미리보기는 가로·세로 동일한 축척(1cm당 20 SVG 단위)을 사용합니다.

사각팩은 빨간색, 원형팩은 파란색입니다.

## 팩 번호와 도착맵

시작맵 배치를 종료하면 ‘팩 번호 매기기’를 사용할 수 있습니다.
팩을 클릭하면 파레트 오른쪽의 별도 영역에 번호판이 열립니다. 화면 숫자 버튼이나 키보드로 0–999999의 정수 또는 도형 번호 ○(원)·△(세모)·□(네모)·◇(45도 기운 네모)를 입력하고 ‘저장 · 다음’ 또는 Enter로 저장합니다.
저장 후 같은 줄의 오른쪽 다음 팩으로 이동하고, 없으면 아래쪽 다음 줄의 가장 왼쪽 팩으로 이동합니다. 빈칸과 빈 줄은 건너뛰며 마지막 팩에서는 번호판이 닫힙니다. 시작맵과 도착맵 모두 같은 순서를 사용합니다.
번호판이 열린 동안 현재 팩은 강조 표시되며, 다른 팩을 직접 클릭해 편집 위치를 바꿀 수도 있습니다.
같은 숫자나 도형 번호를 여러 팩에 사용할 수 있습니다. 모든 팩에 번호를 지정해야 번호 매기기를 완료할 수 있습니다. ‘닫기’나 Escape는 입력 중인 변경을 저장하지 않습니다. 입력 오류가 있으면 다음 팩으로 이동하지 않습니다.

번호 매기기를 완료하면 ‘도착맵 만들기’를 사용할 수 있습니다.
시작맵과 같은 파레트에서 별도의 배치도를 만들며, 시작맵의 종류·크기별 수량만 사용할 수 있습니다.
예를 들어 시작맵에서 사각팩 소를 2개 사용했다면 도착맵에서도 최대 2개만 배치됩니다.
같은 종류·크기의 팩은 시작맵 배치 순서대로 남은 팩을 사용하고 그 팩의 번호를 유지합니다.
배치한 팩을 지우면 해당 팩이 남은 수량으로 돌아옵니다. 다른 종류로 교체할 때도 수량을 초과할 수 없습니다.
시작맵의 모든 팩을 배치해야 도착맵을 완료할 수 있습니다. ‘시작맵 보기’로 원래 배치를 확인할 수 있습니다.

도착맵 배치를 완료하면 ‘도착맵 팩 번호 매기기’를 누르고 팩을 클릭해 번호판을 열 수 있습니다.
숫자 버튼과 키보드로 시작맵에 있는 같은 종류·크기의 팩 번호를 지정합니다.
이미 다른 위치에서 사용 중인 번호를 입력하면 두 위치의 팩 번호가 교환됩니다.
시작맵 번호는 변경되지 않으며, 같은 번호의 팩이 여러 개여도 각각 별도의 팩으로 관리하여 종류·크기별 수량을 유지합니다. 현재 번호를 다시 저장하면 해당 팩을 그대로 유지합니다.
‘도착맵 팩 번호 매기기 완료’를 누르면 번호 편집을 종료합니다.

## 3D 보기

그리기나 배치를 마친 상태에서 ‘3D로 보기’를 누르면 현재 시작맵 또는 도착맵을 입체로 볼 수 있습니다.
선택한 파레트만 표시하며, 한 칸의 밑면은 4 × 4cm입니다. 2D와 3D 모두 팩의 폭·지름 2cm가 칸 변 길이의 정확히 절반이 되도록 표시합니다.
사각팩은 폭·깊이 2cm인 빨간 직육면체, 원형팩은 지름 2cm인 파란 원기둥으로 표시합니다.
높이는 두 종류 모두 소·중·대 각각 4·5·6cm이며 팩 번호도 표시됩니다.
마우스·한 손가락 드래그 또는 방향키로 회전하고, 휠·두 손가락 제스처·확대/축소 버튼으로 크기를 조절합니다.
‘시점 초기화’로 전체 파레트 중심의 바로 위에서 수직으로 내려다볼 수 있습니다.
팩 번호는 2D에서 흰색으로, 3D에서는 흰색 글자를 팩 윗면에 직접 표시합니다. 파레트 칸 번호는 팩이 이동한 뒤에도 원래 위치에 남습니다.
‘2D로 보기’ 또는 편집 버튼으로 기존 배치와 번호를 유지하며 돌아옵니다.
3D 보기에는 WebGL을 지원하는 브라우저가 필요하며, 지원하지 않으면 오류를 안내하고 2D 편집은 유지합니다.
Three.js 0.180.0과 OrbitControls는 MIT 라이선스에 따라 vendor/three에 포함되어 외부 CDN 연결이나 설치가 필요하지 않습니다.

## 경로 추가와 이동 재생

시작맵 배치를 마치고 ‘경로 추가하기’를 누른 뒤 `[[9,8,18,16,11],[21,16,18,8,9]]` 같은 배열을 입력합니다.
숫자는 팩 번호가 아닌 **파레트 칸 번호**입니다. 첫 경로는 9번 칸의 팩을 8·18·16번을 거쳐 11번 칸으로 이동합니다.
경로들은 배열 순서대로 실행되며, 뒤 경로는 앞 경로의 이동 결과에서 출발합니다.
‘입력 완료 · 재생’을 누르면 경로 전체를 검증한 뒤 자동으로 재생합니다.
선택되지 않은 파레트 칸, 팩이 없는 출발 칸, 다른 팩이 있는 경유·도착 칸은 오류로 안내하고 재생하지 않습니다.
지점 사이는 직선으로 이동하며, 지정하지 않은 중간 칸을 통한 충돌 회피 경로는 자동 생성하지 않습니다.

2D와 3D에서 실제 팩 이동을 볼 수 있고 일시정지·이어서 재생·처음으로 돌아가기를 지원합니다.
재생 중 2D/3D를 전환하면 일시정지되며 ‘이어서 재생’으로 계속할 수 있습니다.
경로 미리보기는 시작맵의 별도 복사본을 사용하여 원본 시작맵·도착맵과 팩 번호를 변경하지 않습니다.
도착맵이 있으면 재생 결과가 도착맵과 일치하는지도 표시합니다. 편집 모드로 들어가거나 경로 패널을 닫으면 미리보기가 종료됩니다.

시작맵이나 파레트를 수정하면 배치·번호 완료 상태를 다시 확인해야 합니다.
시작맵에서 삭제되거나 교체된 팩은 도착맵에서도 제거되며, 남아 있는 팩의 번호와 유효한 도착 위치는 유지됩니다.

## 다층 파레트

작업 공간 위의 ‘1층·2층·3층’ 버튼으로 편집할 층을 전환합니다. 각 층은 파레트 모양, 시작맵·도착맵, 팩 번호, 입력 경로와 편집 상태를 독립적으로 유지하며 자동 저장됩니다.
층마다 파레트 번호는 0번부터 계산됩니다. 경로의 위치 번호는 현재 층 안에서 해석합니다.
3D 보기에서는 생성한 층을 같은 가로·세로 좌표에 쌓아 표시합니다. 1층 높이는 0cm, 2층은 8cm, 3층은 16cm이며 층간 간격은 8cm입니다.
위에서 내려다볼 때 위층이 아래층을 가릴 수 있으므로 드래그로 회전해서 전체 층을 확인하세요.
기존 단층 자동 저장 데이터는 1층으로 복원됩니다.

## 자동 저장

파레트, 시작맵·도착맵, 숫자·도형 팩 번호, 종류별 선택 상태와 입력한 경로를 현재 브라우저의 localStorage에 자동 저장합니다.
입력 중인 팩 번호와 편집 단계도 복원합니다. 중복 번호 팩은 별도의 객체 식별을 유지합니다.
변경 후 약 0.2초 뒤 저장하며 페이지를 나가거나 숨길 때도 저장합니다. 제목 옆에 저장 중·저장됨·실패 상태가 표시됩니다.
같은 기기와 브라우저에서 같은 사이트에 다시 접속하면 복원됩니다. 브라우저 사이트 데이터를 삭제하면 저장된 작업도 삭제됩니다.
3D 카메라 위치와 경로 재생 중간 위치는 복원하지 않으며, 입력한 경로를 시작맵에서 다시 재생할 수 있습니다.
손상된 저장 데이터는 별도의 백업 키에 보존한 뒤 새 작업으로 시작합니다. 저장 공간 부족·차단 시에는 실패 상태를 표시하고 현재 화면의 편집 기능을 유지합니다.
